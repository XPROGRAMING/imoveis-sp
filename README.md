# 🏘️ Previsão de Aluguel em São Paulo

Análise e modelo preditivo para estimar o valor de aluguel de imóveis em São Paulo com base em características como área, localização, número de quartos e vagas de garagem.

---

## Sobre o projeto

O objetivo é responder uma pergunta simples: dado um imóvel com determinadas características, qual deveria ser o valor justo do aluguel?

Para isso, trabalhei com um dataset real de mais de 11 mil imóveis em São Paulo, passando por análise exploratória, limpeza dos dados e construção de um modelo preditivo.

---

## O que foi feito

- Análise exploratória completa: distribuição de preços, ranking de bairros mais caros, correlação entre variáveis e relação entre área e aluguel
- Limpeza e tratamento: remoção de outliers extremos e registros inconsistentes
- Dataset final com 11.425 imóveis prontos para modelagem
